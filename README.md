Static-first Astro site deployed from GitHub to Cloudflare Pages. Cloudflare Pages deployment is **not yet verified**. Production origin and DNS will be set only after confirming actual project/domain configuration.

## Quality bar
Helpful, clearly sourced guidance; real working calculators/checklists; semantic HTML, accessible UI, honest safety limitations, measured performance, verified SEO technical readiness. Publishing volume is not a quality metric.
