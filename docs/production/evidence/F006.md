## Search results and distinction
- [HomeEquityMath](https://homeequitymath.com/home-maintenance-cost-calculator): home value, age and a 1–4% preset, plus Census data. The Upkeep Atlas tool instead accepts independently editable lower/target/upper rates and compares planned spending with a separately existing reserve.
- [NovaCalculator](https://www.novacalculator.com/everyday-life/home/home-maintenance-budget-calculator/): age/climate multipliers and a suggested emergency-fund figure. Upkeep Atlas avoids unverified multipliers and arbitrary emergency-fund fractions.
- [Calcly](https://calcly.com/home/maintenance/home-maintenance-budget/): value percentage with optional multiplier. Upkeep Atlas provides transparent three-scenario arithmetic and two distinct funding-gap explanations, without implied repair-cost prediction.
- [TheCalcTools](https://thecalctools.com/home-maintenance-cost-calculator/): percent and square-foot heuristics. Upkeep Atlas omits unsupported cost-per-square-foot defaults.

## Formula and quality
Annual scenario = home value × percentage / 100; monthly = annual / 12. Planned-spending comparison = max(0, target − planned annual spend). Existing-reserve gap = max(0, target − existing reserve), with an illustrative 12-month contribution. These comparisons are **not additive**. Input bounds: positive home value up to $100m, ordered percentages 0.1–20, nonnegative spending/reserve up to $100m. No storage or API transfer. Tests cover exact values, rounding boundary, zero gaps, invalid values and ordering.
