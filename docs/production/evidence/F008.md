## Risks and release gates
Low-risk organizational function. Browser localStorage is not encrypted, may be wiped, and is accessible to others sharing a browser profile; exported CSV may contain personal data. UI explicitly warns against sensitive information and requires confirmation before destructive import/erase. CSV formula-like fields are escaped for spreadsheet opening. 500-row and 1 MB import limits, strict dates and costs. No third-party media needed: a text-first log and data table communicate the task better. No new asset license claims.
