## Original contribution

A seven-day, three-moment printable log tied to exact moisture location, room RH (only if actually measured), weather, ordinary activities, change and photo identifiers. Decision table explicitly avoids inferring a leak, mold species or glazing failure from visual evidence. Distinct from A015's condensation-versus-leak general guide: this is a repeatable **winter-specific longitudinal record**.
