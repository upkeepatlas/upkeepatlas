Reviewed 2026-11-09 UTC. Scope: platform quality, not a new homeowner keyword landing page. Search volume, CPC, difficulty, ranking and Core Web Vitals: **UNMEASURED**. No Lighthouse/CrUX or keyboard/screen-reader field test has been completed in this run.

## Purpose and changes

The generated-output SEO check previously verified the presence of a meta description and unique titles but did not detect duplicate descriptions or malformed JSON-LD. Added checks across every registered public route for both issues. This is a targeted regression prevention improvement, not a claim of a complete WCAG 2.2 AA or all-tool audit.
